
# Dice Rolling Simulation

A simple Python-based dice rolling simulation that generates a random dice result between 1-6 and displays the result using ASCII-style dice faces.

## Features

- Simulate a standard six-sided dice

- Random dice result generator

- Dice faces are displayed using ASCII characters

- Rolling dice with a short delay

- User can roll the dice multiple time

- A fun interactive command-line experience

## Used Technologies

- Python

- Random module

- Time module

## How It Works

1. The program starts the dice simulator

2. The user presses ENTER to roll the dice

3. A random number between 1-6 is generated

4. The corresponding ASCII dice face is displayed

5. The rolled number is shown

6. The user can decide whether they want to roll the dice again or not
